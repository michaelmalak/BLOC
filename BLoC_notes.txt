This program repacks the Atari segmented binary-load format. It does not
insert a general-purpose decompressor. Runs of at least five zero bytes are
candidates for omission, with new four-byte segment headers used to describe
retained ranges. Address thresholds and special cases remain as compiled.
Whether omission is appropriate for a particular target program depends on
that program and the memory state when it loads.

Strings and credits

The raw literals include the title "bloc", "binary load compressor", and
credits for "the nybbler maniacs", "OF  WASHINGTON, D.C.", and
"yoho software,inc.". Their capitalization, inverse-video bits, and graphics
characters are preserved in the native source files. The {HH} convention in
the readable listing records each original byte without relying on a font.

Original quirks retained

Line 30 rejects the signature only if BOTH bytes differ from 255 (AND).
Line 220 can fall through into the title screen when its condition is false.
Line 8220 puts the quotient/high byte before the remainder/low byte in one
new end-address field. Line 8410 writes decimal 53744 ($D1F0).
These are observations of the supplied executable, not proposed corrections.
Changing any of them would break exact reproduction. Their consequences
have not been independently exercised in a full Atari emulation session.

Recovery boundaries

The result retains original executable behavior, including any original
